# Amphora

[English](README.md) · **Русский**

Запуск программ и игр Windows на macOS. Без Windows и без виртуальной машины.

## Что делает

Перетащили `.exe` — программа работает. Amphora читает файл, понимает, что ему
нужно, собирает отдельное окружение Windows и проверяет результат настоящими
кадрами на экране. Если что-то не пошло — говорит, что именно, и предлагает
кнопку, которая это чинит.

Продукт — это автоматизация и диагностика: ровно тот вечер, который иначе
уходит на каждую игру и повторяется после каждого обновления.

## Установка

```sh
curl -fsSL https://github.com/s1rne/amphora/releases/latest/download/install.sh | bash
```

Требуется macOS 14 или новее. Установщик сначала проверяет систему и говорит,
чего не хватает, до того как что-то скачает.

**Почему командой, а не двойным щелчком.** macOS блокирует всё, что скачано
браузером, почтой или мессенджером, — дело в метке «карантин», которую вешают
они, а не в самой загрузке. `curl` её не ставит. Это не обход Gatekeeper:
решение запустить программу принимаете вы, просто явно.
[Установщик](scripts/install.sh) короткий и читается за тридцать секунд.

> Так будет не всегда. Подпись Developer ID и нотаризация в работе; после них
> установка станет обычным перетаскиванием, а команда останется для тех, кому
> удобнее терминал.

## Что вы получаете

**Настройки подбираются сами.** У каждой программы своё окружение, собранное
под неё. Вам не нужно выбирать режим трансляции графики, версию Windows или
набор библиотек — это и есть работа, ради которой продукт существует.

**Проверка кадрами, а не догадкой.** Совместимость подтверждается тем, что на
вашей машине рисуются кадры и измеряются, а не таблицей, которую кто-то
однажды заполнил.

**Отказ объясняется.** Программа не запустилась — вы получаете причину
человеческими словами и кнопку, а не простыню из журнала.

**Всё можно отменить.** Любая операция, способная разрушить окружение, сначала
снимает копию — сама, без вопросов. Если пересборка сломала то, что вчера
работало, одна команда возвращает всё обратно вместе с установленным внутри.

**Всё делается из терминала.** Интерфейс не умеет ничего сверх командной
строки:

```sh
alias amphora=/Applications/Amphora.app/Contents/Resources/amphora-cli

amphora add ~/Downloads/setup.exe   # разбор, план, сборка, установка, проверка
amphora list
amphora run <id>
amphora check <id> --deep           # проверить кадрами
amphora fix <id>                    # применить предложенное лечение
amphora rollback <id>               # вернуться к рабочему состоянию
amphora usage                       # сколько занято места
```

## Границы, названные заранее

Обещать «запускает всё» было бы враньём. Честно:

- обычные программы Windows — как правило да;
- игры на DirectX 11 и старше — да;
- DirectX 12 — работает, медленнее и не везде;
- **игры с античитом уровня ядра — нет.** Античиту нужен настоящий драйвер
  Windows, а его нет ни в одном решении для Mac, включая платные. Amphora
  предупреждает до того, как вы скачаете игру, а не после;
- 16-битные программы — нет.

## Витрина

```sh
amphora catalog          # что можно поставить
amphora get 7zip         # поставить
```

Витрина — не магазин и не хранилище: запись это имя, описание и **адрес у
самого разработчика**. Скачивается только бесплатное и только с домена автора;
платное ведёт на страницу покупки. Правило проверяется кодом, а не
подразумевается — см. [docs/catalog.ru.md](docs/catalog.ru.md). Данные
каталога свободны для любого использования.

## База профилей свободна

Профиль — это знание о том, что нужно одной конкретной игре. Вычислить его
нельзя, его можно только добыть запуском, потратив вечер.

Каталог [`profiles/`](profiles/) намеренно выведен из-под лицензии продукта и
свободен для любого использования кем угодно. Причина простая:
вечер, потраченный одним человеком, не должен тратиться следующим — в том
числе тем, кто пользуется другим продуктом.

Как прислать свой — [CONTRIBUTING.ru.md](CONTRIBUTING.ru.md).

Дальше Amphora станет платной — одной ценой за весь продукт, без уровней и без
подписки:

| | |
|---|---|
| Продукт целиком, разовая покупка | **29 $**, включая год обновлений |
| Продление обновлений | 15 $ в год, по желанию |
| Пробный период | 14 дней, продукт целиком, без карты |
| Возврат | 30 дней без объяснений |

Что стоит знать заранее, чтобы потом не было неожиданностью:

- **купленная версия работает вечно.** Продление даёт новые версии, а не право
  запускать имеющуюся;
- **лицензия проверяется без интернета.** Подписанный ключ лежит на вашей
  машине; игра не должна требовать сети, чтобы запуститься;
- **всё, что установлено в бете, остаётся рабочим.** Продукт, однажды
  забравший у людей работавшее, второго доверия не получает;
- база профилей и каталог остаются свободными при любой цене.
